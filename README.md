## Git Rule
### 커밋 타입
- Feature: 기능 구현
- Fix: 버그 수정
- Refactor: 코드 리팩토링
- Style: 코드 스타일 변경
- Docs: 문서 수정
- Test: 테스트 코드 추가
- Chore: 잡일

### 브랜치 이름
- Feature/#이슈번호/Rakhyunn(깃허브 이름)
- Fix/#이슈번호/Rakhyunn(깃허브 이름)
